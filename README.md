# Cricket Arena Live

A fresh, standalone cricket website project with a mobile-first frontend and Node.js API backend.

## Planned modules
- Phone-number authentication using Firebase Authentication SMS OTP
- Live cricket matches and ball-by-ball commentary via a licensed cricket data provider
- User profiles and secure backend-controlled wallet ledger
- Dedicated admin API and administration UI
- Audit trail and deployment guides

## Repository layout
- `frontend/` — React + Vite mobile-first website
- `backend/` — Node.js + Express API
- `docs/` — setup and production integration notes

## Important
Live scores require a valid provider account/API key. Real deposits and withdrawals require an approved payment provider, verified server-side webhooks, reconciliation, and applicable compliance review. Wallet writes are never trusted from the browser. No fake live score data or production credentials are committed.
